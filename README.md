# odin-rock-paper-scissors

A Rock Paper Scissors game played against the computer, built with JavaScript for The Odin Project.

**Live preview:** https://jan-christopher-buen.github.io/odin-rock-paper-scissors/

## How to play

Click Rock, Paper, or Scissors. The computer picks at random, the result of each round appears on the page, and the first player to reach 5 points wins the game.

## What I practiced

- Planning each step with pseudocode before writing code
- Functions, conditionals, and `Math.random()`
- Logical operators (`&&` and `||`) to decide the winner of a round
- DOM manipulation: buttons, event listeners, and updating text on the page
- Refactoring a console-only game into a game with a user interface
- Git branches: building the UI on a feature branch and merging it into `main`
